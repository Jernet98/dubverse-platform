# Dubverse — publicación inicial

Versión estática preparada para GitHub y Vercel.

## Incluye

- Catálogo público de proyectos
- Estudios relacionados
- Episodios y reproductores externos
- Buscador y filtros
- Diseño responsive

## Importante

Esta primera publicación no incluye todavía el panel administrativo real ni una base de datos persistente. El panel se conectará posteriormente a Neon con autenticación segura.

## Despliegue en Vercel

No necesita comando de compilación. Vercel puede servir los archivos HTML, CSS, JavaScript e imágenes directamente.
