DUBVERSE 2.0 — ORDEN DE PUBLICACIÓN

1) En GitHub elimina los archivos de la versión estática anterior o crea un repositorio nuevo.
2) Sube TODO lo que está dentro de esta carpeta. package.json debe quedar en la raíz.
3) Vercel detectará Next.js automáticamente. No escribas Build Command ni Output Directory.
4) Crea una base de datos en Neon.
5) Copia la cadena de conexión de Neon.
6) En Vercel > Dubverse > Environment Variables agrega:
   DATABASE_URL
   ADMIN_ACCESS_KEY
   AUTH_SECRET
7) Marca Production, Preview y Development para las tres variables.
8) Ejecuta un Redeploy.
9) Abre /setup y pulsa "Crear o actualizar base".
10) Abre /admin e inicia sesión con ADMIN_ACCESS_KEY.

OPCIONAL PARA IMÁGENES:
11) Vercel > Storage > Create Database > Blob > Public.
12) Conéctalo al proyecto. Vercel agregará BLOB_READ_WRITE_TOKEN.
13) Redeploy. Los botones "Subir" del panel quedarán activos.

Si Vercel muestra un error, copia el texto o manda captura. No reinicies Neon ni borres el repositorio sin revisar primero el error.

Puedes ejecutar GENERAR_SECRETOS.bat para crear ADMIN_ACCESS_KEY y AUTH_SECRET aleatorios.
No subas esos valores a GitHub; se pegan únicamente en Vercel.
